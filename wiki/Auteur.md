# Martial Zinsou

**Inventeur & développeur principal d'aiOS** — un système d'exploitation de nouvelle génération basé sur Chromium OS, augmenté d'un agent IA local sécurisé.

---

## Parcours

- **Architecte sécurité** : conception de modèles de moindre privilège, confirmation humaine obligatoire, journal d'audit chaîné (SHA-256).
- **Ingénieur systèmes** : noyau Linux, Chromium OS, sandboxing, capacités POSIX, build reproductible (Gentoo/Portage).
- **Développeur Python** : bibliothèques standard-only, zéro dépendance runtime, protocoles JSON stricts, tests exhaustifs (130+).
- **Auteur** : documentation technique complète, diagrammes UML (Mermaid), site statique « liquid glass » généré depuis le wiki GitHub.

---

## Philosophie

> **L'IA doit servir l'utilisateur, pas l'inverse.**

aiOS incarne cette conviction : un agent qui raisonne localement, ne quitte jamais la machine, demande confirmation avant toute écriture, et laisse une trace inviolable de chaque décision. Aucune télémétrie, aucun compte cloud, aucune exfiltration possible.
